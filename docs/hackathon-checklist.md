- [ ] Dirty-tree/deletion/binary/custom-build coverage and stronger general protected-path rules.

These future items are not inferred mandatory PDF requirements. Do not add another benchmark merely to check a box. Reopen testing for a concrete code defect, evaluator configuration change or explicit acceptance gap.
